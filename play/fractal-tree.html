Fractal tree

A trunk splits into two branches, each rotated by ±φ and scaled by r, and every branch does the same again. Defaults match the original Python script: 10 levels, 30°, 0.67.

how it works

Each branch is stored as a start point, a heading θ and a length m. A child gets heading θ ± φ and length m·r, and its start is the parent’s end. The original FractalTree.py builds the levels as arrays (level i has 2i branches) and plots them with matplotlib; this page does the same level by level in JavaScript, scaling the trunk so the whole tree fits the frame.

Things to try: φ = 90° gives an H-tree; r above about 0.7 lets branches overlap; φ near 0 collapses everything into a single line.
