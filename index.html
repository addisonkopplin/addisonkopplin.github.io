String & Pendulum

Free browser tools for making line art from thread and pendulums. Nothing is uploaded: everything runs on your computer.

Tools

String Art Maker

Turns a photo into string art: one thread wound between nails spaced evenly around a circle.

At each step it picks the straight line between two nails that crosses the darkest part of the image, then lightens those pixels so later lines cover other areas. It prints a numbered nail template and the winding sequence.

Open the String Art Maker

Harmonograph Maker

Draws the curves traced by a harmonograph, a machine in which swinging pendulums move a pen across paper.

Sliders set the frequency, phase, amplitude, and damping of up to three pendulums. Download the drawing as SVG for a pen plotter or laser cutter, or as PNG. The page address stores the settings, so a link reopens the same drawing.

Open the Harmonograph Maker

Spirograph Maker

Draws the curves made by a pen in a wheel that rolls inside or outside a fixed ring, and Lissajous figures, which combine two perpendicular sine waves.

Sliders set the ring and wheel radii, the pen position, and the number of turns, or the frequencies and phase of a Lissajous figure. Download the drawing as SVG, a single continuous line for a pen plotter, or as PNG. The page address stores the settings, so a link reopens the same drawing.

Open the Spirograph Maker

Prices vs. Inflation

Shows how much the price of one category, such as rent, groceries, or auto repair, has changed since a year you choose, next to the change in overall prices.

It covers 32 categories, most from January 2000, using official price indexes from the U.S. Bureau of Labor Statistics. A table ranks every category, and the page address stores the choice, so a link reopens the same comparison.
