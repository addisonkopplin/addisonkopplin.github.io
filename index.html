Projects

String art generator

string_art on GitHub

Python, NumPy

  • Converts a photo into string art: one thread wound between nails spaced evenly around a circle.
  • At each step, the program picks the straight line between two nails that crosses the darkest part of the image. It then lightens those pixels so that later lines cover other areas.
  • The output is the order in which to wind the thread around the nails.
  • The image shows a portrait of Albert Einstein made from 5,000 lines on 288 nails.

fractal_tree on GitHub

Python, NumPy, Matplotlib
